GPU em Detalhe

GTX 1650 — O que suporta

SUPORTADO

CUDA 13.2

GPU compute para IA, rendering, video processing. Driver atualizado abril 2026 com suporte completo.

SUPORTADO

EEVEE Realtime

Rasterizacao em tempo real no Blender. Performance excelente para previews e animacoes.

LENTO MAS OK

Cycles CUDA

Ray tracing com CUDA. Funciona, mas e lento em cenas complexas (30min-4h por frame).

NAO SUPORTADO

OptiX (RTX)

Requer placas RTX. GTX 1650 nao tem RT Cores. Use CUDA como alternativa.

INSUFICIENTE

SDXL / Flux / SD3

Precisam de 8-33 GB de VRAM. Com 4 GB, inviavel. Apenas SD 1.5 512x512 funciona.

INSUFICIENTE

Video Gen Local

Wan2.1, AnimateDiff, CogVideoX — todos precisam 8 GB+ VRAM. Use servicos cloud.

Como Claude controla o After Effects

Geracao de Imagens

SD 1.5 — Unico viavel com 4 GB

⚠️
4 GB VRAM e o limite minimo para geracao de imagens
SD 1.5 funciona em 512x512 com flags de otimizacao. SDXL, Flux e SD 3.5 precisam de 8-33 GB e sao inviáveis. Para imagens de alta qualidade, use APIs cloud (Midjourney, DALL-E, Ideogram).
ModeloVRAM MinResolucao MaxViavel?
SD 1.5 ~4 GB 512 x 512 Sim (lento, apertado)
SDXL 8 GB+ 1024 x 1024 Nao
SD 3.5 Medium 18 GB+ 1024+ Nao
Flux.1 33 GB+ 1024+ Impossivel

Prioridade 1 — Claude no After Effects (Hoje)
1

Instalar o MCP de After Effects

Clone o repositorio mais popular e configure no Claude Desktop.

git clone https://github.com/Dakkshin/after-effects-mcp cd after-effects-mcp npm install
2

Adicionar ao Claude Desktop config

Edite o arquivo de configuracao do Claude Desktop em %APPDATA%\Claude\claude_desktop_config.json

{ "mcpServers": { "after-effects": { "command": "node", "args": ["C:/path/to/after-effects-mcp/index.js"] } } }
3

Instalar o painel CEP no After Effects

Copie o painel para a pasta de extensoes do AE e habilite extensoes nao assinadas nas preferencias.

# Pasta de extensoes no Windows: C:\Users\[user]\AppData\Roaming\Adobe\CEP\extensions\
4

Testar com o Claude

Abra o Claude Desktop, depois o After Effects, e experimente:

"Crie uma nova composicao 1920x1080 30fps com um texto 'Hello World' no centro, fonte Arial 72px, cor branca, com um fade in de 30 frames"
Prioridade 2 — LLM Local com Ollama
1

Instalar Ollama

winget install Ollama.Ollama --source winget
2

Baixar o modelo Qwen3 4B

Melhor modelo para 4 GB VRAM. ~2.8 GB de download.

ollama pull qwen3:4b ollama run qwen3:4b
3

Usar no AE GPT (plugin)

Configure a URL local http://localhost:11434 no plugin AE GPT para usar modelos locais gratuitos dentro do After Effects.

Prioridade 3 — Blender + MCP
1

Instalar Blender

winget install BlenderFoundation.Blender --source winget
2

Instalar Blender MCP addon

# No terminal Python do Blender ou pip: pip install blender-mcp # Ou via GitHub: ahujasid/blender-mcp
3

Configurar CUDA no Blender

Edit > Preferences > System > Cycles Render Devices. Selecione CUDA e marque a GTX 1650. Use EEVEE para trabalho rapido, Cycles para renders finais.

Prioridade 4 — TTS Local
1

Instalar Coqui XTTS v2

pip install TTS tts --model_name tts_models/multilingual/multi-dataset/xtts_v2 \ --text "Ola, este e um teste de voz clonada" \ --speaker_wav minha_voz.wav \ --language_idx pt \ --out_path output.wav
2

Para TTS ultra-leve (CPU): Piper

pip install piper-tts echo "Texto para narrar" | piper --model pt_BR-edresson-low \ --output_file narration.wav
Prioridade 5 — Imagens com ComfyUI
1

Instalar ComfyUI

git clone https://github.com/comfyanonymous/ComfyUI cd ComfyUI pip install -r requirements.txt python main.py --lowvram --gpu-only
2

Baixar modelo SD 1.5

Coloque o .safetensors em ComfyUI/models/checkpoints/. Use apenas SD 1.5 — SDXL nao funciona com 4 GB VRAM.

⚠️
Limitacao: apenas 512x512
Com 4 GB VRAM, resolucoes maiores causam out-of-memory. Para imagens de alta qualidade, use Midjourney, DALL-E 3, ou Ideogram via API.
